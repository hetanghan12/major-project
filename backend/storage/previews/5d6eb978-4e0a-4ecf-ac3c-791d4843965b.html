1. Project Title

Secure Cloud Storage Platform with Private AI Assistant

2. Problem Statement

In many organizations and educational environments, users store documents digitally but face difficulty in: - Quickly finding relevant information inside documents - Understanding large documents - Managing personal data securely

Existing AI tools often use public or mixed data, which raises privacy and security concerns.

3. Proposed Solution

We propose to build a cloud-based web application where: - Each user gets personal cloud storage - Users can upload documents (PDF, DOC, TXT, etc.) - An AI assistant answers questions only from the user’s uploaded documents - User data is fully isolated and secure

The AI assistant will not access data from other users, ensuring complete privacy.

4. Key Features

  • User registration and login
  • Secure document upload
  • Cloud-based document storage
  • Dedicated page to view and download uploaded files
  • AI assistant for question answering
  • AI responses based only on user data
  • Workflow automation using n8n
  • Vector-based document search

5. System Architecture Overview

High-Level Flow

  1. User logs in to the system
  2. User uploads documents
  3. Documents are stored securely in cloud storage
  4. Text is extracted from documents
  5. Text is converted into vector embeddings
  6. Vectors are stored in Pinecone with user-specific separation
  7. User asks a question
  8. AI assistant retrieves relevant document data
  9. AI generates and returns an answer

7. Data Security & Privacy

  • Each user has a unique user ID
  • Documents are stored in user-specific folders
  • Pinecone uses separate namespaces per user
  • AI assistant can only access the current user’s data
  • No data sharing between users

8. Database Design (Overview)

User Data

  • User ID
  • Email
  • Account creation date

Document Data

  • Document ID
  • User ID
  • File name and type
  • Storage path
  • Upload timestamp

Vector Metadata

  • User ID
