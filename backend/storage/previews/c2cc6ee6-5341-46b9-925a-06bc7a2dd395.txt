End‑to‑End Documentation: Fine‑Tuning an Audio‑to‑Text (ASR) Model on NVIDIA DGX Spark



1. Purpose of This Document

This documentation explains step‑by‑step how to fine‑tune a pretrained audio‑to‑text (speech recognition) model locally on NVIDIA DGX Spark, assuming zero prior knowledge of model training.

By following this guide, you will: - Set up the system correctly - Install all required software - Prepare audio and text data - Fine‑tune a pretrained ASR model - Run inference (audio → text)

This is not training from scratch. It is fine‑tuning, which is the correct and industry‑standard approach.



2. What You Are Actually Doing (Simple Explanation)

Speech‑to‑Text models are already trained on millions of hours of audio. Training again from zero is inefficient. Instead, we:

Take a pretrained ASR model

Give it your own audio + text

Slightly adjust (fine‑tune) its weights

Get a model that works better for your data (accent, language, domain)

11. Audio Data Preparation

This section explains why audio formatting matters and what happens if it is wrong.

ASR models do not understand compressed or multi-channel audio. They expect a fixed, clean signal.

Why these rules exist: - WAV → uncompressed, no information loss - 16 kHz → model was trained at this sampling rate - Mono → avoids channel mismatch errors - PCM → raw numerical audio samples

If these conditions are not met, training may: - Crash immediately - Train but give very poor accuracy - Waste GPU time

Audio Rules (Mandatory)

Format: WAV

Sample rate: 16 kHz

Channels: Mono

Encoding: PCM

Convert audio if needed:

ffmpeg -i input.mp3 -ar 16000 -ac 1 output.wav

Place all .wav files in:

data/audio/



12. Create Manifest Files (Critical Step)

This is the most important file creation step in the entire pipeline.

Manifest files act as a bridge between your audio files and the model.

The model does NOT scan folders automatically. It only reads what is written in the manifest.

Each JSON line answers four questions: 1. Where is the audio file? 2. What words are spoken? 3. How long is the audio? 4. Is the path absolute and correct?

If even ONE path is wrong, training will fail.

Manifest files tell the model: - Where audio is located - What text is spoken - How long the audio is

Example train.json

{"audio_filepath": "/home/harsh/asr_training/data/audio/sample1.wav", "text": "hello how are you", "duration": 3.2}

Each line must be valid JSON.

Create: - data/manifests/train.json - data/manifests/val.json



13. Download Pretrained ASR Model

python

from nemo.collections.asr.models import EncDecCTCModelmodel = EncDecCTCModel.from_pretrained("nvidia/stt_en_conformer_ctc_large")model.save_to("models/pretrained_asr.nemo")

Exit Python.



14. Training Configuration File

This file controls how training behaves.

Think of train.yaml as the remote control for training.

Explanation of key parameters: - manifest_filepath → tells the model which data to read - batch_size → number of audio samples processed together - devices → number of GPUs to use - max_epochs → how many full passes over the dataset

Wrong values here will: - Cause out-of-memory errors - Slow training - Underfit or overfit the model

Create configs/train.yaml

model:  train_ds:    manifest_filepath: /home/harsh/asr_training/data/manifests/train.json    batch_size: 32  validation_ds:    manifest_filepath: /home/harsh/asr_training/data/manifests/val.json    batch_size: 16trainer:  devices: 1  accelerator: gpu  max_epochs: 10



15. Training Script

This Python file is the execution engine.

What happens inside train.py step by step: 1. Load configuration from YAML 2. Restore pretrained ASR model 3. Initialize GPU trainer 4. Start fine-tuning 5. Save the new model

This script does NOT define the model architecture. It only: - Loads - Trains - Saves

That is why fine-tuning is simpler than training from scratch.

Create scripts/train.py

from nemo.collections.asr.models import EncDecCTCModelfrom pytorch_lightning import Trainerfrom omegaconf import OmegaConfcfg = OmegaConf.load("configs/train.yaml")model = EncDecCTCModel.restore_from("models/pretrained_asr.nemo")trainer = Trainer(**cfg.trainer)trainer.fit(model)model.save_to("models/fine_tuned_asr.nemo")



16. Start Training

cd ~/asr_trainingpython scripts/train.py

You will see GPU usage and training logs.



17. Test the Model (Inference)

from nemo.collections.asr.models import EncDecCTCModelmodel = EncDecCTCModel.restore_from("models/fine_tuned_asr.nemo")model.transcribe(["test.wav"])
