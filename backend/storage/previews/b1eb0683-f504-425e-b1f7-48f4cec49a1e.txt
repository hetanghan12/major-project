LTX‑2 Setup and Usage Guide on NVIDIA DGX Spark

Overview

This guide explains how to install and run the LTX‑2 text‑to‑video model on an NVIDIA DGX Spark system.It includes environment preparation, dependency installation, model download, running inference,and integrating the model with an API.Target hardware: NVIDIA DGX Spark with GB10 / Blackwell architecture GPUTarget OS: Ubuntu 22.04 / 24.04Framework: PyTorch + CUDA

Step 1 – Verify System Requirements

Open a terminal and verify GPU, Python, and Docker installation.Commands:nvidia-smipython3 --versiondocker --versionIf nvidia-smi displays your GPU information, the GPU driver is working correctly.

Step 2 – Install NVIDIA Container Toolkit (Recommended)

Install NVIDIA Container Toolkit so Docker containers can access the GPU.Commands:sudo apt-get updatesudo apt-get install -y ca-certificates curl gnupgcurl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpgcurl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.listsudo apt-get updatesudo apt-get install -y nvidia-container-toolkitsudo nvidia-ctk runtime configure --runtime=dockersudo systemctl restart dockerTest GPU in Docker:docker run --rm --gpus all nvidia/cuda:12.4.1-base-ubuntu22.04 nvidia-smi

Step 3 – Clone the LTX‑2 Repository

Install Git and FFmpeg, then clone the repository.sudo apt updatesudo apt install -y git ffmpeggit clone https://github.com/Lightricks/LTX-2.gitcd LTX-2

Step 4 – Install Python Environment Using UV

Install the UV environment manager.curl -LsSf https://astral.sh/uv/install.sh | shCreate the virtual environment and install dependencies:uv sync --frozensource .venv/bin/activate

Step 5 – Download Model Weights

Create folders for storing models:mkdir -p ~/ltx2_models/checkpointsmkdir -p ~/ltx2_models/upscalersmkdir -p ~/ltx2_models/lorasmkdir -p ~/ltx2_models/gemmaDownload required files from HuggingFace:• LTX‑2 checkpoint• Spatial upscaler• Temporal upscaler• Distilled LoRA• Gemma text encoderPlace them inside the directories created above.

Step 6 – Run Text‑to‑Video Generation

Example command:python -m ltx_pipelines.ti2vid_two_stages --checkpoint-path ~/ltx2_models/checkpoints/ltx-2-19b-distilled.safetensors --distilled-lora ~/ltx2_models/loras/ltx-2-19b-distilled-lora-384.safetensors 0.8 --spatial-upsampler-path ~/ltx2_models/upscalers/ltx-2-spatial-upscaler-x2-1.0.safetensors --gemma-root ~/ltx2_models/gemma --prompt "A cinematic drone shot of a futuristic city at sunset" --output-path output.mp4After the command finishes, the generated video will be saved as output.mp4.

Step 7 – Access the Generated Video

Open the video with:xdg-open output.mp4Or download the file from the server to your local machine.

Step 8 – Optional: Create an API for the Model

You can expose the model as an API using FastAPI.Example architecture:Frontend → API Request → FastAPI Backend → LTX‑2 Model → Generated Video → ResponseThis allows integration with websites, SaaS tools, and automation workflows.

Recommended Project Structure

ltx-video/  models/  outputs/  scripts/  api/  ui/Example output:outputs/video_001.mp4

Performance Tips

• Use distilled checkpoints for faster inference• Use FP16 / FP8 quantization for lower VRAM usage• Reduce frame count for faster generation• Use NVLink multi‑GPU if available on DGX systems

Conclusion

NVIDIA DGX Spark provides excellent hardware for running LTX‑2 text‑to‑video models.By following this guide, you can generate AI videos locally, integrate them into APIs,and build AI applications or SaaS platforms.
